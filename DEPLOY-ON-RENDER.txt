IMPORTANT: Deploy this project as a Render WEB SERVICE, not a Static Site.

In Render:
1. New + -> Blueprint (recommended), then connect the GitHub repository containing these files at its ROOT.
2. Or create New + -> Web Service, Runtime Node, Build Command: npm install, Start Command: npm start.
3. Attach a PostgreSQL database and set DATABASE_URL, SESSION_SECRET, ADMIN_PASSWORD. ADMIN_USERNAME is optional (default admin).

Do not set a Publish Directory. This is a Node.js server-rendered application; it does not use a static-site index.html. The Express server serves the dashboard at / and login at /login.

Monthly payroll table is created automatically on deployment; no manual SQL migration is needed.
